## O que é a Plegma DAG?

A Plegma é um protocolo de registro distribuído baseado em **DAG (Grafo Acíclico Dirigido)** com criptografia pós-quântica nativa. Não somos uma blockchain linear. Não temos CEO. Não temos escritório. Somos matemática que roda em código.
